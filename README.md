# Bachu Sai Portfolio

A React portfolio built with Vite.

## Run locally

```sh
npm install
npm run dev
```

## Add your files

The resume from the supplied file is included at `public/resume.pdf`. Put your
profile photo at `public/profile.jpg`; the photo placeholder remains visible
until a valid image is present.

## Build and publish

```sh
npm run build
```

Upload the generated `dist` folder at [Netlify Drop](https://app.netlify.com/drop)
to publish the site and get a public URL. Add `public/profile.jpg` and
`public/resume.pdf` before building if you want them included in the live site.
